# CIS 774 Programming Paradigms — Python OOP Examples

This repository contains Python 3 examples used with the **Object-Oriented Design with Python** lecture in **CIS 774 Programming Paradigms**.

## Open in GitHub Codespaces

1. Open this repository on GitHub.
2. Click **Code**.
3. Select the **Codespaces** tab.
4. Click **Create codespace on main**.
5. Wait for the Codespace to finish building.

The repository includes a `.devcontainer/devcontainer.json` configuration, so the Codespace opens with Python 3 and the VS Code Python extension.

## Run an example

Open the terminal in the Codespace and run, for example:

```bash
python examples/01_class_example.py
```

You can run the other examples in the same way.

## Examples

| File | Topic |

| `01_class_example.py` | Class, constructor, method, destructor |
| `02_constructor.py` | `__init__()` constructor |
| `03_class_and_object.py` | Class vs. instance attributes |
| `04_inheritance.py` | Inheritance |
| `05_multiple_inheritance.py` | Multiple inheritance |
| `06_self.py` | `self` |
| `07_private_attributes.py` | Double-underscore attributes |
| `08_name_mangling.py` | Name mangling |

| `10_operator_polymorphism.py` | Operators with different data types |
| `11_repr_example.py` | `repr()` |

## Python version

The examples use **Python 3** syntax. They were adapted from the lecture presentation, which contained some older Python 2 syntax.
